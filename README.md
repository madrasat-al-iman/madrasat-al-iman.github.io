# מדרשת האמונה · مدرسة الإيمان

אתר המאגר הדו־לשוני (עברית וערבית) של מקבילות בין התורה, הנביאים והכתובים וספרות חז״ל לבין הקוראן והחדית׳.

## מה יש באתר

- **ספר ב׳ · פירוש האסלאם לתורה:** 54 פרשות לפי יחידות. בכל יחידה מופיעים נוסח המסורה ותרגום ון־דייק, אחריהם המקבילות מהקוראן ומהחדית׳, ובמקומות הרלוונטיים הערות מתפסיר רס״ג.
- **ספר א׳ · עם הספר לקוראן:** 114 סורות בערבית ובתרגום עברי. ליד הפסוקים מופיעים הערות תרגום, מקבילות לפי פסוק וקישורים חוזרים למקרא.
- **נביאים וכתובים:** המקבילות לפי ספר.
- **ספר ג׳ · מקבילות לפי נושאים:** נושאים וסיפורים, ולכל אחד עיקר ההשוואה, מראי מקום, שאלות לחברותא ועיון בדמיון ובשוני.
- **נספחים:** מחלוקות יסוד עתיקות, שורשים תאומים, פנינים מקבילות וצומתי מפגש היסטוריים.
- **חדית׳:** הנוסח הערבי, ותרגום לעברית היכן שיש.
- **כלים:**
  - חיפוש בכל המאגר.
  - תצוגה בעברית, בערבית או בשתיהן.
  - שינוי גודל הגופן ומצב לילה.
  - קישורים ישירים לכל פסוק ולכל מקבילה.
  - העתקת ציטוט דו־לשוני.
  - השמעת פסוקי קוראן.
  - הזמנה ללימוד בחברותא בווידאו (Jitsi).
  - הדפסה.

## עדכון הנתונים

האתר קורא את התוכן מקובצי JSON שבתיקייה `data/`. הקבצים נוצרים משלושת קובצי המאגר:

```
python3 tools/build_data.py "מאגר א׳.xlsx" "מאגר ב׳.xlsx" "מאגר ג׳.xlsx"
```

אחרי ההרצה מעלים את התיקייה `data/` המעודכנת, והאתר מציג את המצב החדש.

ההרצה יוצרת גם:
- `c/`, `b/`, `a/`, `n/` – עמוד סטטי מלא לכל נושא, פרשה, סורה וספר בנביאים ובכתובים. בכל עמוד הטקסטים המלאים בעברית ובערבית, נתונים מובנים ותצוגה מקדימה לשיתוף. העמודים מיועדים למנועי חיפוש ולקישורים משותפים, ומקשרים לעמוד האינטראקטיבי באתר.
- `sitemap.xml` ו־`robots.txt`.
- טבלת „פרשת השבוע“ (לפי המנהג בארץ ישראל), שנבנית בעזרת הספרייה `pyluach`: `pip install pyluach`.

כתובת האתר הציבורית נקבעת בקובץ `site.json`. הסקריפט משתמש בקורפוס מקרא מקומי. את מיקומו קובעים במשתנה הסביבה `MIDRESHET_WORK`.

## מקורות ומהדורות

- **נוסח המקרא:** מקרא על פי המסורה, בלי טעמים.
- **התרגום הערבי למקרא:** ון־דייק (1865), נחלת הכלל.
- **נוסח הקוראן:** הכתיב העות׳מאני.
- **החדית׳:** לפי מספור sunnah.com; במוסלם לפי מספור עבד אל־באקי.
- **התרגומים לעברית:** של הקוראן ושל החדית׳ הם טיוטת המאגר.

האתר הוא גרסת עבודה, וחלק מהחומר עדיין לא עבר בדיקה אנושית.
